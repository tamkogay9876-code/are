# 3D asset manifest

The current Three.js scene creates these original procedural assets at runtime:

| Asset | Type | Purpose |
|---|---|---|
| Northgate booth | Modular box geometry | Main playable space |
| Secure door and window | Box meshes | Visitor entrance |
| Desk, legs and drawers | Box meshes with material variations | Inspection workstation |
| Monitor and keyboard | Meshes plus canvas label texture | Records terminal |
| Emergency telephone | Base, keypad, handset and buttons | 998 interaction |
| Resident ID | Card, portrait and record lines | Identity inspection |
| Magnifying glass | Ring, transparent lens and handle | ID inspection feedback |
| Desk lamp | Base, stem, shade and point light | Local warm light |
| Plant | Pot and seven leaf meshes | Room dressing |
| Operator chair | Seat, back, pole and five legs | Foreground dressing |
| Visitor | Low-poly body, head, arms, legs, shoes and eyes | Incoming resident |
| Security camera | Body and emissive lens | Environmental storytelling |
| Warning beacon | Cylinder with emissive material | Emergency status cue |

No downloaded or third-party model files are currently bundled. These are genuine 3D meshes, but they are procedural prototype assets rather than production-quality sculpted or rigged models. The separately authored Blender scene is available from the linked 3D Jutsu project.
