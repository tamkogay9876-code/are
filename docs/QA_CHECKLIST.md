# QA checklist

## Day phase

- [ ] Start a new shift from the menu.
- [ ] Confirm a resident record is displayed.
- [ ] Test allow, deny, and 998 dispatch.
- [ ] Ask all available questions and check the evidence log.
- [ ] Hold right mouse over the ID and confirm magnification.
- [ ] Check that the day phase ends after the configured visitor limit.

## Night phase

- [ ] Drive and confirm time and fuel change.
- [ ] Check radio and confirm an evidence note is added.
- [ ] Use the single-shell defense and verify it cannot be reused.
- [ ] Test arrival at HQ and the breakdown ending.

## Persistence and layout

- [ ] Save a game, refresh, and continue.
- [ ] Clear the save from the main menu.
- [ ] Verify the interface at desktop, tablet, and narrow mobile widths.
- [ ] Run `npm test` and `npm run build`.
